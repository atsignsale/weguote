# WE-QUOTE — PEA Quotation & Mobile Generator Fleet Management System
ระบบประมาณการค่าบริการและบริหารจัดการคิวเครื่องกำเนิดไฟฟ้าเคลื่อนที่ กฟฉ.1

## 📌 คุณสมบัติหลัก (Key Features)
1. **Dashboard & Analytics:** ภาพรวมรายได้, สถิติการปฏิบัติงาน, และแผนที่พิกัด 17 จุดรวมงาน
2. **PEA Cover Quotation:** คำนวณค่าบริการฉนวนครอบสายและอุปกรณ์ป้องกันสัตว์
3. **Generator Rental & Logistics:** คำนวณขนาดโหลดไฟฟ้า (kW/Amp), ระยะทางขนส่ง, ค่าเชื้อเพลิง และพยากรณ์ค่าใช้จ่าย
4. **Queue & Fleet Management:** ระบบปฏิทินคิวงาน 24 เครื่อง, ค้นหาเครื่องว่างที่ใกล้ที่สุด, และปักหมุดพิกัดแผนที่ (Leaflet OpenStreetMap)
5. **Quotation History & PDF:** บันทึกประวัติใบเสนอราคาและพิมพ์เอกสารมาตรฐาน PEA

## 🚀 การ Deploy บน Vercel
โปรเจกต์นี้เป็น Single Page Application (Static Web) พร้อมใช้งาน สามารถเชื่อมต่อ Repository กับ [Vercel](https://vercel.com) และกด **Deploy** ได้ทันทีโดยไม่ต้องตั้งค่า Build Command เพิ่มเติม
